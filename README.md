## About

LEBWPOLISH is an independent language-learning platform that brings vocabulary, grammar, writing, reading, listening and everyday communication into one practical learning space. From building your first sentence to developing confidence at B1 level, learners can practise at their own pace.

**Learn. Practise. Remember. Improve.**

The platform emphasizes active recall, contextual exercises, spaced repetition, meaningful feedback and consistent learning habits rather than passive memorization.

## Learning experiences

### Guided learning

Daily Journey offers twelve learning missions and thirty-six exercises, flexible starting levels, daily goals, Memory Garden vocabulary review and B1 Compass skill reflection.

| Activity | Learning objective |
| --- | --- |
| Daily Journey | Guided missions and progressive practice |
| One Word Closer | B1 sentence completion and vocabulary recall |
| Vocabulary Vault | Practical vocabulary organized by topic |
| Grammar Codex | Grammar explanations, examples and challenges |
| Sentence Forge | Construct meaningful sentences |
| Verb Workshop | Practise Polish conjugation |
| Polish Arcade | Vocabulary and sentence-building games |
| Role-play Studio | Communication in realistic situations |
| Listen & Write | Listening and written recall |
| Reading Practice | Stories and contextual vocabulary |
| Writing Studio | Writing prompts and self-review |
| B1 Grammar Challenge | Apply grammar in context |

### One Word Closer

A contextual sentence-completion game featuring sixty original B1-oriented sentences, typing and multiple-choice modes, spaced repetition, mastery levels, explanations, XP, streaks and progress backup and restoration. Available within the platform and as a standalone HTML experience.

### Practice Studio and Polish Arena

Practice Studio combines translation exercises, Polish character input, pronunciation, speech recognition where supported, grammar hints and existing XP mechanics. Polish Arena offers Spin & Learn, Phantom Words, Duel Mode against a computer and Story Mode for contextual decisions.

### Community and creative learning

Community Writing Space, Polish through music, role-play and Meme Lab encourage expression and participation. Meme Lab is designed to display all community memes accessible under Firestore permissions, with optional personal filtering, search, likes, comments and translation reveal. Some community features require an account.

## Progress and learner experience

Depending on the activity and account status, learners can track mission completion, vocabulary review, mastery, XP and streaks; retain writing drafts, preferences, favourites and recent activities; and synchronize supported progress with their account. Supported guest activities use local browser storage.

Quick Notes provides a convenient place for vocabulary, grammar observations and personal reminders. Optional background music, responsive layouts, SVG iconography, clear navigation, branded loading states and keyboard-friendly interactions support regular practice.

## Getting started

### Prerequisites

Node.js 20.19+ or 22.12+, npm, Git and a modern web browser.

```bash
git clone https://github.com/Byadiso/lebwpolish.git
cd lebwpolish
npm ci
npm run dev
```

Open the local URL printed by Vite.

### Environment configuration

Create a `.env` file in the project root using your own Firebase web application configuration:

```dotenv
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-storage-bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your-sender-id
VITE_FIREBASE_APP_ID=your-app-id
VITE_FIREBASE_DATABASE_URL=https://your-project-default-rtdb.europe-west1.firebasedatabase.app
VITE_FIREBASE_MEASUREMENT_ID=your-measurement-id
```

Use the actual database URL supplied by Firebase. The measurement ID is optional for the initialization shown in the project. Configure authentication providers, database and storage rules, and the existing Cloudinary upload configuration for the features you intend to use. Never place private service-account credentials or Cloudinary API secrets in frontend environment variables; `VITE_` values are exposed to the browser.

## Deployment and releases

**Live application:** https://lebwpolish.netlify.app/

Netlify deployment settings:

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Publish directory | `dist/` |
| Environment variables | Configure Firebase web settings in Netlify |
| Routing | Single-page application fallback to `index.html` |

Develop changes on dedicated branches, review them through pull requests, run tests and verify a deployment preview before merging into the production branch. Publish a GitHub release after validating the deployed version.

The V2 upgrade uses the branch `feature/v2-premium-active-learning`. The planned release tag is `v2.0.0`; the release badge above reflects published releases rather than planned versions.

## Privacy and security

LEBWPOLISH includes administrator-only visitor statistics intended to understand platform usage, including guest and authenticated sessions, page visits and engagement duration.

Read the [Privacy Policy](https://lebwpolish.netlify.app/privacy). 

## Learning scope

LEBWPOLISH supports A1–B1 language development and B1-oriented preparation. It is not a complete certification course, an official assessment of exam readiness or a substitute for authentic listening, extended speaking and writing practice.

Official examination information: [certyfikatpolski.pl](https://certyfikatpolski.pl/).
