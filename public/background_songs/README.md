# LEBWPOLISH background soundtrack

Place your licensed music file here and name it `background.mp3`.
The site loads it from `/background_songs/background.mp3` (respecting the Vite base URL).

The soundtrack loops continuously, plays at 22% volume, and persists across in-app navigation.
Visitors can toggle it off at any time; their choice is remembered in localStorage.
Browsers may require the visitor's first interaction before playing audible audio.
No music file was supplied with this project, so you must add your own MP3.
